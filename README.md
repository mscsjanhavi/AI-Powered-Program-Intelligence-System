# 📊 AI-Powered Program Intelligence Dashboard

A live AI-powered program management dashboard that tracks task health, 
predicts delays, and generates automated executive reports.

## 🎯 Problem It Solves
Program managers waste hours manually tracking task status, estimating 
delays, and writing status reports. This system automates all of it 
with ML-based predictions and one-click AI report generation.

## ✨ Features
- 📊 Real-time KPIs — Total Tasks, Completed, Delayed, High Risk
- 📈 Task Status Distribution and Estimated vs Actual Hours charts
- 🔥 Risk Overview table with colour-coded risk scoring
- 🤖 ML-based Task Delay Predictor (Planned Duration + Hours input)
- 🧠 One-click AI Report Generator
- 🔍 Dynamic filters by Owner and Status

## 🧠 Tech Stack
`Python` `Streamlit` `Pandas` `Scikit-learn`
